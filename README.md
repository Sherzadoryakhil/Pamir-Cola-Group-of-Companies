## About the Project

This project is a **university project focused on redesigning the real website of Pamir Cola Group of Companies, an Afghan beverage brand**. The goal is to improve the website's visual design, responsiveness, accessibility, and user experience while presenting the company's products, brand identity, and corporate information.

The website was developed using **HTML5, CSS3, and Vanilla JavaScript**, without any frameworks.

**Note:** This is an independent university redesign project, not an official website developed or endorsed by Pamir Cola Group of Companies.

## Features

- 📱 Responsive design for mobile, tablet, and desktop.
- 🌙 Light and dark themes with saved preferences.
- 🌐 English and Dari language switching with RTL support.
- 🔍 Searchable and filterable product catalogue.
- 🎬 Promotional video gallery.
- 🏢 Company information, news, mission, vision, values, and branches.
- ✉️ Contact form with inline validation.
- ♿ Accessibility features, including keyboard navigation and visible focus indicators.
- 🖼️ Placeholder images for missing media assets.

## Website Pages

- `index.html` — Homepage, product catalogue, promotional videos, and brand logos.
- `about-us.html` — Company information, news, branches, and contact form.
- `videos.html` — Promotional video gallery.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Sherzadoryakhil/Pamir-Cola-Group-of-Companies.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.

**Note:** Image and video assets are not included. Create the required media folders and add files using the expected filenames.
